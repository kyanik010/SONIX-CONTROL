# SONIX CONTROL

مركز الإدارة المركزي لتطبيق SONIX TV.

- واجهة إدارة عربية حديثة ومتجاوبة.
- إدارة الأجهزة والاشتراكات والسيرفرات عبر NOVA-CONTROL backend الحالي.
- إدارة السيرفرات وتخصيص سيرفر واحد أو أكثر لكل جهاز، مع إظهار اسم السيرفر في تطبيق العميل.
- إنشاء وتعديل الثيمات وألوانها وتحديد الثيم الافتراضي الذي تتم مزامنته مع التطبيق.
- إرسال رسائل لجميع الأجهزة أو لجهاز محدد، مع تسليمها عند تشغيل التطبيق أو عودته للعمل وتأكيد الاستلام لمنع التكرار.

> مشروع Supabase الحالي يبقى باسم NOVA-CONTROL كمعرّف تقني للخلفية؛ الاسم الظاهر للمشرفين والعملاء هو SONIX CONTROL.
