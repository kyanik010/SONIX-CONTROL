# SONIX CONTROL

مركز الإدارة المركزي لتطبيق SONIX TV.

- واجهة إدارة عربية حديثة ومتجاوبة.
- إدارة الأجهزة والاشتراكات والسيرفرات عبر NOVA-CONTROL backend الحالي.
- أنظمة الثيمات والرسائل المركزية قيد تنفيذ خدماتها الخلفية وربطها بالأجهزة.

> مشروع Supabase الحالي يبقى باسم NOVA-CONTROL كمعرّف تقني للخلفية؛ الاسم الظاهر للمشرفين والعملاء هو SONIX CONTROL.
